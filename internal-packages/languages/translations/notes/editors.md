# Editors translator context (module 07)

These messages are interface copy for `packages/editors`. They never replace authored IIIF language maps, content language tags, IDs, MIME values, URI/selector strings, coordinates or creation defaults. The base locale is British English, with complete Dutch (`nl`) and complete English/Dutch plain wording overlays. The host enables Dutch explicitly. Shared action verbs resolve through the existing `common` namespace; editor-api system property/resource names, layout presets, behavior choices, rights names/descriptions and documentation summaries use their supplied message references with legacy fallback.

- `fields`, `metadata`: headings for system fields, never values typed by an author. Label becomes Title/Titel in plain wording. `metadata.value` is the value half of a metadata pair. A required statement is a credit/rights notice; its label and value are separate authored language maps.
- `canvas` and `ui.*Canvas*`, `ui.*Manifest*`, `ui.*Range*`: the standard IIIF canvas/manifest/range terminology is replaced by page/item/section in plain wording. Translate the complete sentence, including articles and prepositions. Dutch uses canvas/canvassen, pagina/pagina's, manifest and bereik/bereiken in these editor controls; the shared editor-api resource definitions may retain the protocol term Range. These are UI words, never serialized `type` values.
- `ui.*layout*`, `ui.*Layout*`, `ui.*size*`, `ui.*Size*`, `messages.layouts*`, `messages.resize_*`: image arrangement and geometry controls. Applying a layout replaces manual positioning; resizing can clip images. Width and height are pixel values. Resize keys name each edge/corner as a complete accessible action. “Shift” names the keyboard key, not translation of the word shift. The layout callback retains its original preset ID and rectangles.
- `language`, `ui.languageAndFormat`, `ui.*Html*`, `ui.text*`, `ui.*Text*`: authoring controls for plain text, rich text and literal HTML source. Switching to plain text can destroy formatting, so the full confirmation must explain the effect. HTML is a technical abbreviation, not an untranslated English sentence. Imported source may remain incomplete while the author types.
- `ui.heading1/2/3`, `ui.bulletList`, `ui.numberedList`, `ui.quote`, `ui.bold`, `ui.italic`, `ui.underline`, `ui.link`, `ui.blockStyle`, `ui.image`, `ui.linkUrl`, `ui.imageUrl`, `ui.altText`, `ui.unlink`, `ui.insert`: text toolbar choices and link/image forms, not the format or type of an authored IIIF resource.
- `ui.*behavior*`, `ui.*Behavior*`: built-in behavior names and choices normally come from editor-api. Custom behavior inputs preserve the exact authored extension string. `messages.unsupportedBehavior` reports the pre-existing unimplemented template editor; it does not imply template editing is implemented.
- `ui.choice*`, `ui.*Choice*`, `ui.*option*`, `ui.*Option*`, `messages.combine*`, `messages.options*`: grouping image annotations as viewer-selectable alternatives. “Unwrap choice” converts those alternatives back to separate painting annotations. Removing an option differs from deleting the image resource.
- `messages.annotationNotFound`, `notPainting`, `alreadyChoice`, `expectedImage`, `bodyNotFound`, `onlyImages`: reasons a media candidate cannot be combined into a choice. These are interface explanations, unlike the separate developer guard errors thrown by invalid helper calls.
- `annotationTypes`: display descriptions of rendering strategies, never protocol type discriminants. “Service” is a IIIF image service. “AV” means audiovisual; “3D model” names the resource category.
- `navDate`, `messages.previousMonth/nextMonth/previousYear/nextYear/calendarUp`, `messages.second/amPm/invalidDate`: accessible names and invalid-input feedback for the navigation/sorting date. Locale can change the displayed order and calendar month names, but cannot reinterpret the stored timestamp or timezone. `AM/PM` names the time period selector.
- `reorder`: screen-reader keyboard instructions, sortable-role description and live announcements. Space lifts/drops; arrows move; Escape cancels. Positions are one-based ordinals derived from list order. No resource identifier is translated or used as an ordinal.
- Other `ui` entries label annotation drawing tools, preview fallbacks, linking/technical forms, caption tracks, image services, action menus, empty/error states and definition metadata. “Untitled…” describes a missing display title; never save that translated fallback into authored data. Technical examples retain `jpg`, `png`, `painting` and `supplementing` exactly because users enter those values.

## Interpolation and counts

Translate each whole message, keeping placeholders unchanged:

| Placeholder       | Context                                                                                                                                                                                                                    |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `count`           | Numeric cardinal in `canvas.count`, `messages.layouts`, `messages.combine`, `messages.options`, `messages.annotations`. Supply `_one` and `_other` for Dutch, not an English suffix or fragment.                           |
| `number`          | One-based media/option/metadata/custom-behavior/image-position number, not an authored ID.                                                                                                                                 |
| `position`        | One-based list position in reorder live announcements.                                                                                                                                                                     |
| `width`, `height` | Pixel dimensions, carried unchanged to callbacks; use the multiplication sign between them where supplied.                                                                                                                 |
| `language`        | Locale-aware name of the authored content tag, including safe verbatim fallback for invalid/unknown tags. `none` is translated separately. This is not restricted to UI language availability.                             |
| `label`           | Display field name or authored resource title, depending on the key: `field*` uses a field label; `editNamed/selectNamed/viewNamed/runNamed/pauseNamed` can include authored text. Never translate the interpolated title. |
| `value`           | Exact custom behavior string in `removeBehavior`; do not translate or normalize it.                                                                                                                                        |
| `action`          | Optional host-supplied display action in `actionNamed`; preserve it as interpolation.                                                                                                                                      |

`unchanged-nl.json` records exact-source reviews for real Dutch cognates/technical abbreviations only (Media, Logo, HTML, Canvas, west and numbered Media). A changed source invalidates its review. English fallback/defaultValue never counts as Dutch completion.
